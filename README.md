# Rideshare_X — Peer-to-Peer Cost-Sharing Carpooling Platform

A modern, responsive web application for genuine peer-to-peer intercity travel cost sharing.

> **Important Principle:** Rideshare_X is not a commercial taxi or ride-hailing platform. Drivers are everyday commuters sharing their personal journeys to offset fuel consumption and highway tolls—with zero surge pricing or commercial markups.

---

## 🌟 Key Features

- **Three Dedicated Portals:**
  - 🚗 **Driver / Car Owner:** Mandatory document verification, ride creation wizard, available seats allocation, booking request management, and refundable cancellation deposit escrow.
  - 👤 **Passenger / Co-traveller:** Intercity route search, interactive seat selection (`[-] 1 [+]`), booking tracking, and cancellation protection.
  - 🛡️ **Admin Panel:** Driver verification approval, ride & booking management, and cancellation deposit dispute resolution.
- **Active Ride & Live GPS Telemetry:**
  - Real-time animated vehicle position along the route.
  - Telemetry HUD: Live speed, ETA, and progress.
  - Route deviation safety alerts & Expressway optimization toggle.
  - Emergency SOS protocol linked with 112 National Helpline.

## 🚀 Getting Started

### Local Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
```

### GitHub Pages Deployment
```bash
npm run deploy
```
